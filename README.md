# bank
A simple bank application to utilize bandwidth of DevOps tech.

In this application I have made a simple static website with 1 landing page and 1 form page to take userdata and store it in a db.
The purpose of this project is to make a 3-tier application on cloud utilizing docker containers for hosting the pages on aws.
This project was made to learn:
- How to use docker, creation of docker images and containers.
- Use AWS ECR and ECS to host the application and use ECS as load balancer on an application.
- Make a full-fledged pipeline from github to aws while making a production level project to understand market challenges.
- Clear the understanding and working of concepts of DevOps and cloud.
